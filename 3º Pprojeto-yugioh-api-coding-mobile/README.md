# 🃏 Yu-Gi-Oh Card Viewer

Aplicação web desenvolvida para exibir **cartas aleatórias de Yu-Gi-Oh**, apresentando informações detalhadas como tipo, atributo, nível, ataque, defesa e descrição da carta.

O projeto consome dados de uma **API pública de cartas de Yu-Gi-Oh** e exibe essas informações dinamicamente na interface.

---

## 🚀 Demonstração

A aplicação pode ser acessada através do link:

https://puxarcartas-yugioh.netlify.app

---

## 📋 Funcionalidades

- Exibição de **carta aleatória de Yu-Gi-Oh**
- Apresentação das principais informações da carta:
  - Nome
  - Tipo
  - Atributo
  - Nível
  - Ataque (ATK)
  - Defesa (DEF)
  - Descrição da carta
- Atualização dinâmica das informações
- Interface simples e intuitiva
